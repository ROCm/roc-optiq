**********************
Systems Profiler trace view keyboard shortcuts  
********************** 

Use these shortcuts in the ROCm Systems Profiler trace view.

.. list-table::
     :header-rows: 1
     :widths: 60 40

     * - Action
       - Shortcut
     * - Pan left or right
       - ``A`` / ``D`` or ``Left`` / ``Right``
     * - Scroll tracks up or down
       - ``Up`` / ``Down``
     * - Pan or scroll faster (2x)
       - ``Shift`` + the above
     * - Zoom in and out at the cursor
       - ``W`` / ``S``
     * - Select a time range
       - ``Ctrl`` + left-drag
     * - Mark selected events as a time range, or clear them
       - ``M``
     * - Zoom to the selected time range
       - ``Z``
     * - Clear the time range selection
       - ``Esc``
     * - Multi-select events
       - ``Ctrl`` + click
     * - Save the current view to a bookmark
       - ``Ctrl`` + ``0``-``9``
     * - Restore a bookmark
       - ``0``-``9``
